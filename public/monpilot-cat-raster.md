# MonPilot cat mark

`monpilot-cat.svg` is the canonical vector source for the monochrome brand mark and can be rasterized for desktop or mobile bundles without changing the artwork. For example, export at 64, 128, and 512 pixels with any SVG-capable tool (Inkscape, Illustrator, or a browser screenshot at 1:1 scale). The repository does not currently include a PNG toolchain, so no generated binary is committed.
